---
name: checkpoint-git
description: Validate and commit a coherent milestone using the project Git policy.
---
Main session only. Inspect status/diff and explicit staged paths for secrets/private brief. Run meaningful checks; record evidence. Verify git user identity and branch/upstream. Stage named files, use a conventional 8-10-word subject, no attribution/trailers. Hook failure must be fixed, not bypassed. Commit, inspect author/committer/body, then push configured feature remote. Never force push. If no remote exists, report local commit and concrete remote setup needed.
